CS 320 Enhancement: RESTful API Layer

Modern Web Architecture with Spring Boot

Enhancement Overview

Building upon the solid foundation of Project One, this enhancement transforms the Service Management System into a modern web application by adding a RESTful API layer. The enhancement demonstrates professional software architecture patterns, industry-standard web technologies, and best practices in API design.

Technology Stack: Java, Spring Boot, Maven, JUnit

New Concepts: REST API, HTTP Methods, JSON, Layered Architecture, Dependency Injection

GitHub: View Source Code

What Changed?

The enhancement adds new capabilities while preserving the original functionality:

Before (Project One)

  • Java classes with in-memory storage
  • Direct method calls for operations
  • Local JUnit testing only
  • Single-layer architecture

After (Enhancement)

  • RESTful HTTP endpoints accessible via web
  • JSON request/response format
  • Three-tier layered architecture
  • Dependency injection support
  • Spring Boot framework integration
  • Production-ready API design

RESTful API Endpoints

The system now exposes HTTP endpoints following REST conventions. All endpoints use JSON format for request and response data.

Contact Management API

POST /api/contacts - Create a new contact
DELETE /api/contacts/{contactID} - Delete a contact
PUT /api/contacts/{contactID}/firstName - Update first name
PUT /api/contacts/{contactID}/lastName - Update last name
PUT /api/contacts/{contactID}/phone - Update phone number
PUT /api/contacts/{contactID}/address - Update address

Task Management API

POST /api/tasks - Create a new task
DELETE /api/tasks/{taskID} - Delete a task
PUT /api/tasks/{taskID}/name - Update task name
PUT /api/tasks/{taskID}/description - Update task description

Appointment Management API

POST /api/appointments - Create a new appointment
DELETE /api/appointments/{appointmentID} - Delete an appointment

API Usage Example

Here's how to interact with the API using standard HTTP tools:

Creating a Contact

curl -X POST http://localhost:8080/api/contacts \
  -H "Content-Type: application/json" \
  -d '{
    "contactID": "123",
    "firstName": "John",
    "lastName": "Doe",
    "phone": "1234567890",
    "address": "123 Main St"
  }'

Response (201 Created):
{
  "message": "Contact created successfully with ID: 123",
  "contactID": "123"
}

Updating Contact Phone

curl -X PUT http://localhost:8080/api/contacts/123/phone \
  -H "Content-Type: application/json" \
  -d '{"phone": "9876543210"}'

Response (200 OK):
{
  "message": "Contact phone updated successfully"
}

Deleting a Contact

curl -X DELETE http://localhost:8080/api/contacts/123

Response (200 OK):
{
  "message": "Contact deleted successfully: 123"
}

Key Enhancements

1. Data Access Object (DAO) Layer

New DAO classes encapsulate all data persistence logic:

  • Standard CRUD Operations: save(), update(), delete(), findById(), exists()
  • Optional Returns: Uses Java Optional for null-safe data retrieval
  • Consistent Error Handling: Standardized exception handling
  • Abstraction: Storage implementation can be changed without affecting other layers

2. Controller Layer

Controllers handle user input/output between services and external interfaces:

  • Input Validation: Validates and sanitizes user input
  • Error Messages: User-friendly error reporting
  • Request/Response Formatting: Consistent data formatting
  • Dependency Injection: Flexible component wiring

3. RESTful API Layer

Spring Boot REST controllers expose HTTP endpoints:

  • Standard HTTP Methods: POST, PUT, DELETE used appropriately
  • JSON Format: Industry-standard data interchange
  • Status Codes: Proper HTTP status codes (200, 201, 400, 404, 500)
  • Spring Annotations: @RestController, @RequestMapping, @RequestBody

4. Refactored Service Layer

Services now delegate data operations to DAOs:

  • Business Logic Focus: Services only handle business rules
  • DAO Integration: All data operations delegated to DAO layer
  • Enhanced Documentation: Comprehensive Javadoc comments
  • Backward Compatible: Original tests still pass

Technical Improvements

Separation of Concerns

Each layer has a single, well-defined responsibility, making the codebase more maintainable and testable.

Dependency Injection

Spring Boot's dependency injection container manages component lifecycles and dependencies, enabling easier testing and configuration.

Testability

Layered architecture allows each layer to be tested independently with mock objects.

Scalability

The architecture supports future enhancements like:

  • Database integration (JPA/Hibernate)
  • Authentication and authorization
  • Caching layer
  • Distributed deployment
  • Multiple user interfaces (web, mobile, desktop)

Build and Run

The project uses Maven for dependency management and building:

Prerequisites

  • Java 17 or higher
  • Maven 3.6+

Quick Start

# Navigate to project directory
cd CS_320_Enhancement/CS_320_Project_One_Enhancement

# Build the project
mvn clean package

# Run the application
mvn spring-boot:run

# API available at http://localhost:8080/api

Testing

# Run all tests
mvn test

# Run specific test class
mvn test -Dtest=ContactServiceTest

Enhancement Narrative

This enhancement demonstrates the evolution from a simple console application to a production-ready web service. The transformation showcases several important software engineering skills:

Architectural Design

Implementing a layered architecture improves code organization and maintainability. Each layer has a clear responsibility, and changes in one layer don't cascade to others. This separation makes the codebase easier to understand, test, and extend.

Modern Web Technologies

Adding a RESTful API layer makes the service accessible over HTTP, enabling integration with web applications, mobile apps, or other services. Using JSON as the data format ensures compatibility with virtually all modern programming languages and frameworks.

Framework Integration

Integrating Spring Boot demonstrates understanding of industry-standard frameworks. Spring Boot provides dependency injection, auto-configuration, and production-ready features like health checks and metrics.

Backward Compatibility

The enhancement preserves all original functionality while adding new capabilities. This demonstrates the ability to extend systems without breaking existing functionality—a critical skill in professional software development.

Professional Documentation

Comprehensive documentation ensures that other developers can understand, use, and maintain the system. The documentation includes API references, architecture explanations, and usage examples.
